  <what-built>
    supabase db push applied 0005_programs_schema.sql which added:
    1. is_admin boolean column to user_profiles (default false)
    2. Check constraints program_templates_phases_is_array and program_templates_weeks_is_array on program_templates
    3. RLS policy program_templates_admin_write on program_templates
    4. Table enrolled_program_sessions with columns: id, enrollment_id, week_num, session_index, completed_at, session_workout_id, created_at, updated_at
    5. Unique constraint on (enrollment_id, week_num, session_index)
    6. Index enrolled_program_sessions_enrollment_idx on (enrollment_id)
    7. Trigger enrolled_program_sessions_updated_at
    8. RLS policy enrolled_program_sessions_owner_all
  </what-built>

  <how-to-verify>
    Open the Supabase dashboard for this project and verify each of the following:

    **user_profiles table:**
    - Go to Table Editor → user_profiles
    - Confirm "is_admin" column exists with type boolean, nullable: false, default: false

    **program_templates table:**
    - Go to Database → Tables → program_templates → Constraints
    - Confirm "program_templates_phases_is_array" check constraint exists
    - Confirm "program_templates_weeks_is_array" check constraint exists
    - Go to Authentication → Policies → program_templates
    - Confirm "program_templates_admin_write" policy exists (for ALL operations)
    - Confirm "program_templates_select_all" policy still exists (not deleted)

    **enrolled_program_sessions table:**
    - Go to Table Editor → enrolled_program_sessions
    - Confirm table exists with all 8 columns: id, enrollment_id, week_num, session_index, completed_at, session_workout_id, created_at, updated_at
    - Go to Database → Tables → enrolled_program_sessions → Constraints
    - Confirm unique constraint on (enrollment_id, week_num, session_index)
    - Go to Authentication → Policies → enrolled_program_sessions
    - Confirm "enrolled_program_sessions_owner_all" policy exists

    Alternatively, run these SQL queries in the Supabase SQL editor:
    ```sql
    -- Check is_admin column
    select column_name, data_type, column_default, is_nullable
    from information_schema.columns
    where table_schema = 'public' and table_name = 'user_profiles' and column_name = 'is_admin';

    -- Check constraints on program_templates
    select constraint_name from information_schema.table_constraints
    where table_schema = 'public' and table_name = 'program_templates'
    and constraint_type = 'CHECK';

    -- Check enrolled_program_sessions exists
    select column_name from information_schema.columns
    where table_schema = 'public' and table_name = 'enrolled_program_sessions'
    order by ordinal_position;

    -- Check RLS policies
    select polname, polcmd from pg_policy
    join pg_class on pg_class.oid = pg_policy.polrelid
    where pg_class.relname in ('program_templates', 'enrolled_program_sessions');
    ```

    All queries should return rows matching the expected values.
  </how-to-verify>
